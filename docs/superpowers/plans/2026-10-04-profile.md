# Daily organization profile

**Goal:** Replace the alien profile with useful, automatically refreshed public work.

**Design:** Keep Python and generate GitHub Markdown from the public GitHub API and the writing RSS feed. GitHub Actions runs daily at 11:23 UTC and on manual request; it commits only a changed profile. No external service, private-repository data, or moving “last checked” timestamp.

**Decisions:** Use published GitHub Releases (Doctor Biz confirmed), including labeled prereleases and excluding drafts. List every public repository, including archived repos and forks, in an alphabetical expandable directory. Show the eight most recently pushed active repos separately, excluding this profile repository so its own refresh does not promote it. Show ten most recently published releases across all public repos, with release links and dates. Show five latest research posts. The intro identifies 2389 Research as an applied AI lab in Chicago, with website, research, work-with-us, and contact links.

**Sources:** `https://api.github.com/orgs/2389-research/repos?type=public&per_page=100`, releases for every public repo, and `https://2389.ai/research/writing/index.xml`. Paginate repositories and releases completely, sort by actual dates with stable tie breaks, and escape external text for Markdown. Require successful complete fetches before an atomic write. Identical output leaves the file untouched.
